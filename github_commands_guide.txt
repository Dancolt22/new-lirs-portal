PART 3: HOW TO ADD YOUR STUDENT AS A COLLABORATOR (EXACT CLICK-BY-CLICK)
--------------------------------------------------------------------------------
Once your code is pushed to GitHub, add your student so he has full push/pull
and pull request permissions:

1. In your browser, open your repository page:
   https://github.com/Dancolt22/new-lirs-portal
2. Look at the menu tabs near the top (Code, Issues, Pull requests, Actions, Projects, Wiki, Security, Insights, Settings).
3. Click "Settings" (the gear icon on the far right).
4. In the left-hand sidebar menu, look under the "Access" section and click "Collaborators".
   (GitHub may prompt you to confirm your password or 2FA).
5. Under "Manage access", click the green button: "Add people".
6. In the search pop-up box, type your student's GitHub username or email address.
7. Click on his profile from the dropdown list.
8. Click "Add <username> to this repository".
9. IMPORTANT: GitHub generates a pending invitation!
   - Tell your student to check his email and click "Accept invitation".
   - OR copy the direct invitation link from the screen and send it to him on WhatsApp/Slack:
     https://github.com/Dancolt22/new-lirs-portal/invitations
   - He MUST accept before he can push branches.

--------------------------------------------------------------------------------
PART 5: QUICK TROUBLESHOOTING CHEAT SHEET
--------------------------------------------------------------------------------
Issue 1: "fatal: remote origin already exists"
Fix:
git remote set-url origin https://github.com/Dancolt22/new-lirs-portal.git

Issue 2: "Authentication failed" during git push
Fix:
GitHub no longer accepts account passwords for CLI push.
Use a Personal Access Token (PAT):
1. GitHub -> Settings -> Developer settings -> Personal access tokens -> Tokens (classic)
2. Generate new token (classic) -> tick "repo" scope -> Generate.
3. Paste the token as your password when Git prompts.

Issue 3: Student sees "Permission denied to <user>" when pushing a branch
Fix:
Student has not clicked "Accept invitation" yet.
Send him to: https://github.com/Dancolt22/new-lirs-portal/invitations

Issue 4: Student port collision ("Address already in use")
Fix:
Student kills any orphaned process using:
Get-Process -Name dotnet -ErrorAction SilentlyContinue | Stop-Process -Force
